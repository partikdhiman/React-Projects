# 🎨 Color Changer

A simple **React Color Changer** project that changes the background color of the webpage when a button is clicked.

## 🚀 Features

* Change background color with buttons
* Uses React `useState`
* Styled with Tailwind CSS
* Smooth background color transition

## 🛠️ Technologies Used

* React
* Tailwind CSS
* JavaScript
* Vite

## 📚 What I Learned

* How to use `useState()` in React
* How to update state using `setColor()`
* How to handle `onClick` events
* How to use inline styles in React
* How to use Tailwind CSS classes
* How to use `flex-wrap` for responsive buttons

## ▶️ Run the Project

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
