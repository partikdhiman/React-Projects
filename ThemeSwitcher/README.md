# 🌗 React Theme Switcher

A simple and professional **Light/Dark Mode React application** built using **React Context API** and **Tailwind CSS**.

The project demonstrates how to manage a global theme using Context API and switch between light and dark modes without passing props through multiple components.

---

## 🚀 Features

- 🌞 Light Mode
- 🌙 Dark Mode
- 🔄 Theme toggle switch
- ⚛️ React Context API
- 🎨 Tailwind CSS
- 🧩 Reusable components
- ✨ Smooth hover and transition effects
- 📱 Responsive UI

---

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- React Context API
- Vite
