# Weather App
 
A simple React weather app with live search, condition-based visuals, and dark mode.
 
## Features
 
| Feature              | Description                                  |
|----------------------|-----------------------------------------------|
| City search           | Get live weather for any city                |
| Weather details       | Temperature, feels-like, min/max, humidity   |
| Condition visuals      | Icon and image change by weather condition   |
| Dark mode              | Toggle between light and dark themes         |
| Error handling         | Clear message for invalid city names         |
 
## Tech Stack
 
| Layer      | Technology         |
|------------|---------------------|
| Frontend    | React (Vite)        |
| UI Library  | Material UI (MUI)   |
| Data        | OpenWeatherMap API   |
| Styling     | Plain CSS            |
 
## Setup
 
| Step | Command                          |
|------|-----------------------------------|
| 1    | `git clone <repo-url>`           |
| 2    | `cd weather-react`               |
| 3    | `npm install`                     |
| 4    | Add API key to `.env`            |
| 5    | `npm run dev`                     |
