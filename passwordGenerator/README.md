# 🔐 Password Generator

A simple React app to generate random passwords with customizable length and character options.

## Features
- Adjustable password length (6–99 characters)
- Option to include numbers
- Option to include special characters
- One-click copy to clipboard

## Tech Stack
- React (useState, useEffect, useCallback, useRef)
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

## Usage
1. Move the slider to set password length.
2. Toggle "Numbers" and "Characters" checkboxes as needed.
3. Click **Copy** to copy the generated password.
